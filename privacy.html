Resumen. CURI MUNDO es un canal de YouTube. Para gestionarlo usa una herramienta interna, el «Social Engine de CURI MUNDO», que se conecta a la YouTube Data API v3 y a la YouTube Analytics API solo con la cuenta del propio canal, autorizada por su titular. La herramienta no está abierta al público, no tiene usuarios externos y no recoge datos personales de los espectadores. No vendemos datos.

1. Quién es el responsable

El responsable es el titular del canal de YouTube CURI MUNDO (youtube.com/@curimundoyt). Para cualquier consulta sobre privacidad, escríbenos abriendo una incidencia en github.com/ivnrodrig/curimundo-web/issues.

2. A qué se aplica esta política

Se aplica a:

  • la herramienta interna de gestión del canal («Social Engine de CURI MUNDO»), que es la aplicación registrada en Google Cloud y la que solicita acceso a las API de Google; y
  • este sitio web (ivnrodrig.github.io/curimundo-web).

La herramienta es de uso exclusivo del titular del canal para administrar su propio canal. No se ofrece a terceros, no permite que otras personas inicien sesión y no accede a cuentas ni canales ajenos. Los datos de los espectadores que ve YouTube no llegan a la herramienta salvo de forma agregada y anónima (por ejemplo, el número total de visualizaciones de un vídeo).

3. Datos de Google a los que accede la herramienta

La herramienta usa OAuth 2.0 de Google. El titular del canal concede el acceso; la herramienta solicita, como máximo, estos permisos:

Permiso (scope)Para qué
youtube.readonlyLeer la información y la lista de vídeos del canal.
yt-analytics.readonlyLeer las estadísticas agregadas del canal en YouTube Analytics.
youtube.uploadSubir los vídeos producidos por CURI MUNDO (con su fecha de publicación programada) y poner la miniatura al vídeo recién subido.

YouTube Data API v3

  • Datos del canal propio: identificador, nombre, URL personalizada, fecha de creación, país, número de suscriptores, visualizaciones y vídeos, lista de subidas y estado del canal.
  • Datos de los vídeos propios: identificador, título, descripción, etiquetas, duración, fecha de publicación, estado de privacidad y estadísticas públicas (visualizaciones, «me gusta», número de comentarios).
  • Acciones de escritura sobre el canal propio: subir vídeos nuevos (como privados y programados), establecer la miniatura del vídeo recién subido y comprobar que la publicación quedó como se esperaba. La herramienta no modifica ni elimina vídeos ya subidos: no solicita los permisos que lo permitirían y, además, lo bloquea en su propio código.

YouTube Analytics API

  • Métricas agregadas del canal propio: visualizaciones, minutos vistos, duración y porcentaje medio de visualización, suscriptores ganados y perdidos, «me gusta», comentarios y veces compartido.
  • Desgloses por vídeo, por día, por tipo de contenido (Shorts o vídeos largos), curva de retención de los vídeos con más visualizaciones y tipo de fuente de tráfico.

La herramienta no accede al texto de los comentarios, a listas de suscriptores, a datos demográficos, a mensajes, a información de pagos ni a datos de identificación de ningún espectador.

4. Para qué se usan

  • Generar informes periódicos de rendimiento del canal para tomar decisiones creativas y de calendario.
  • Subir, programar y verificar la publicación de los vídeos del canal en sus horarios.

Los datos no se usan para publicidad, para crear perfiles de personas ni para entrenar modelos de inteligencia artificial, y no se venden.

5. Dónde y cómo se almacenan

  • Credenciales OAuth (identificador y secreto del cliente, token de actualización): se guardan únicamente como secreto cifrado de GitHub Actions en el repositorio privado del proyecto. No se escriben en disco ni en el código, y se ocultan automáticamente en los registros de ejecución.
  • Tokens de acceso: existen solo en memoria durante cada ejecución automática y se descartan al terminar.
  • Informes de Analytics (archivos JSON y Markdown con métricas agregadas): se guardan en el repositorio privado del proyecto en GitHub y como artefactos de GitHub Actions.
  • Registro de publicaciones (identificador y URL de cada vídeo publicado, estado, resultado de la verificación y fecha): se guarda en el mismo repositorio privado.

Antes de guardar cualquier salida, la herramienta la filtra para eliminar credenciales y comprueba de forma automática que no haya fugas de secretos en el repositorio.

6. Con quién se comparten

No vendemos, alquilamos ni cedemos datos a terceros. Solo acceden a ellos el titular del canal y las herramientas de producción que trabajan en su nombre dentro de sus cuentas privadas. Los datos se tratan en la infraestructura de estos proveedores, sujetos a sus propias políticas:

  • Google / YouTube, como origen de los datos a través de sus API.
  • GitHub, que aloja el repositorio privado, ejecuta los procesos automáticos (GitHub Actions) y sirve este sitio web (GitHub Pages).

Solo revelaríamos datos si lo exigiera la ley.

7. Conservación y eliminación

  • Los artefactos de GitHub Actions con informes se eliminan automáticamente a los 90 días.
  • Los informes y registros guardados en el repositorio privado se conservan mientras sean útiles para la gestión del canal y hasta que el titular los elimina.
  • Las credenciales se conservan mientras la herramienta esté en uso. Al dejar de usarla, el titular revoca el acceso (sección 8) y borra el secreto de GitHub Actions; desde ese momento la herramienta no puede volver a acceder a ningún dato de Google.

Para solicitar la eliminación de datos, contacta por el canal indicado en la sección 1.

8. Cómo revocar el acceso

El acceso concedido a la herramienta puede retirarse en cualquier momento desde la página de permisos de la cuenta de Google: myaccount.google.com/connections (también disponible en security.google.com/settings/security/permissions). Al revocarlo, los tokens dejan de funcionar de inmediato.

9. Este sitio web

Este sitio es estático: no usa cookies, no tiene formularios, no carga analítica ni recursos de terceros y no nos envía ningún dato. Lo aloja GitHub Pages; GitHub puede registrar datos técnicos de las visitas (como la dirección IP) según la Declaración de privacidad de GitHub.

10. Políticas de Google y YouTube

La herramienta usa los Servicios de API de YouTube. Al usarla se aplican también las Condiciones de servicio de YouTube y la Política de privacidad de Google.

El uso y la transferencia de la información recibida de las API de Google por parte de esta herramienta se ajustan a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado (Limited Use).

11. Menores

La herramienta solo la utiliza el titular del canal y no recoge datos de menores ni de ninguna otra persona.

12. Cambios y contacto

Si cambia el uso de los datos, actualizaremos esta página y su fecha de vigencia antes de aplicar el cambio. Consultas: github.com/ivnrodrig/curimundo-web/issues.

Summary. CURI MUNDO is a YouTube channel. It is managed with an internal tool, the “CURI MUNDO Social Engine”, which connects to the YouTube Data API v3 and the YouTube Analytics API only with the channel's own account, authorized by its owner. The tool is not open to the public, has no external users and does not collect personal data about viewers. We do not sell data.

1. Who is responsible

The controller is the owner of the YouTube channel CURI MUNDO (youtube.com/@curimundoyt). For any privacy question, contact us by opening an issue at github.com/ivnrodrig/curimundo-web/issues.

2. What this policy covers

It covers:

  • the internal channel-management tool (“CURI MUNDO Social Engine”), which is the application registered in Google Cloud and the one that requests access to Google APIs; and
  • this website (ivnrodrig.github.io/curimundo-web).

The tool is used exclusively by the channel owner to manage their own channel. It is not offered to third parties, does not let other people sign in and does not access anyone else's accounts or channels. Viewer data seen by YouTube only reaches the tool in aggregated, anonymous form (for example, a video's total view count).

3. Google data the tool accesses

The tool uses Google OAuth 2.0. The channel owner grants access; the tool requests, at most, these permissions:

Permission (scope)Purpose
youtube.readonlyRead the channel's information and video list.
yt-analytics.readonlyRead the channel's aggregated YouTube Analytics statistics.
youtube.uploadUpload videos produced by CURI MUNDO (with their scheduled publication time) and set the thumbnail of the newly uploaded video.

YouTube Data API v3

  • Own channel data: ID, name, custom URL, creation date, country, subscriber, view and video counts, uploads playlist and channel status.
  • Own video data: ID, title, description, tags, duration, publication date, privacy status and public statistics (views, likes, comment count).
  • Write actions on the own channel: uploading new videos (as private and scheduled), setting the thumbnail of the newly uploaded video and checking that the publication went as expected. The tool does not modify or delete videos already uploaded: it does not request the permissions that would allow it and also blocks it in its own code.

YouTube Analytics API

  • Aggregated metrics for the own channel: views, minutes watched, average view duration and percentage, subscribers gained and lost, likes, comments and shares.
  • Breakdowns by video, by day, by content type (Shorts or long-form), the audience-retention curve of the most viewed videos, and traffic source type.

The tool does not access comment text, subscriber lists, demographic data, messages, payment information or any identifying data about any viewer.

4. How the data is used

  • To produce periodic channel performance reports used for creative and scheduling decisions.
  • To upload, schedule and verify the publication of the channel's videos at their set times.

The data is not used for advertising, for profiling people or for training artificial-intelligence models, and it is not sold.

5. Where and how it is stored

  • OAuth credentials (client ID and secret, refresh token): stored only as an encrypted GitHub Actions secret in the project's private repository. They are never written to disk or into code, and they are automatically masked in run logs.
  • Access tokens: exist only in memory during each automated run and are discarded when it ends.
  • Analytics reports (JSON and Markdown files with aggregated metrics): stored in the project's private GitHub repository and as GitHub Actions artifacts.
  • Publication log (ID and URL of each published video, status, verification result and date): stored in the same private repository.

Before any output is saved, the tool filters it to remove credentials, and it automatically checks the repository for leaked secrets.

6. Who it is shared with

We do not sell, rent or transfer data to third parties. Only the channel owner and the production tools working on their behalf, inside their private accounts, can access it. The data is processed on the infrastructure of these providers, subject to their own policies:

  • Google / YouTube, as the source of the data through their APIs.
  • GitHub, which hosts the private repository, runs the automated jobs (GitHub Actions) and serves this website (GitHub Pages).

We would only disclose data if required by law.

7. Retention and deletion

  • GitHub Actions artifacts containing reports are deleted automatically after 90 days.
  • Reports and logs stored in the private repository are kept while they are useful for managing the channel and until the owner deletes them.
  • Credentials are kept while the tool is in use. When it is no longer used, the owner revokes access (section 8) and deletes the GitHub Actions secret; from then on the tool cannot access any Google data.

To request deletion of data, use the contact channel in section 1.

8. How to revoke access

Access granted to the tool can be withdrawn at any time from the Google Account permissions page: myaccount.google.com/connections (also at security.google.com/settings/security/permissions). Once revoked, the tokens stop working immediately.

9. This website

This site is static: it uses no cookies, has no forms, loads no analytics or third-party resources and sends no data to us. It is hosted on GitHub Pages; GitHub may log technical visit data (such as IP address) under the GitHub Privacy Statement.

10. Google and YouTube policies

The tool uses YouTube API Services. Using it is also subject to the YouTube Terms of Service and the Google Privacy Policy.

This tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

11. Children

The tool is used only by the channel owner and does not collect data from children or from anyone else.

12. Changes and contact

If the use of data changes, we will update this page and its effective date before applying the change. Questions: github.com/ivnrodrig/curimundo-web/issues.
