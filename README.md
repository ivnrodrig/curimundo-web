# curimundo-web

Sitio oficial de **CURI MUNDO** (canal de YouTube de ciencia y curiosidades en español), servido con GitHub Pages.

- Página principal: https://ivnrodrig.github.io/curimundo-web/
- Política de privacidad / Privacy Policy: https://ivnrodrig.github.io/curimundo-web/privacy.html

Sitio estático (HTML + CSS), sin JavaScript, sin cookies, sin analítica y sin recursos de terceros.
Este repositorio no contiene código de producción, credenciales ni datos del canal.
